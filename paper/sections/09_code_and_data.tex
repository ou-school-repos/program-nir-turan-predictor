\section*{Code and Data Availability}
The C++ search routines, exact integer arithmetic formulations, and SMT
solver scripts supporting the exact finite computations \textbf{(E)}
and bounded sweeps \textbf{(S)} are available in the project
repository. The
\href{https://github.com/sjjaroch/leontovich-utils/tree/7aab6dd68bccd7614794c75333dddc692b53541f}{archival fork at commit \texttt{7aab6dd68bcc}}
is a mirror of the project repository pinned to the exact shared-history
snapshot used for the reported computations. A separate Lean~4 development
formally verifies the two-to-one homomorphism-count identity for connected
properly two-colored sources that underlies Theorem~\ref{thm:double_cover}.
It does not formally verify the full theorem, the named witnesses, or the
computational claims. The Lean certificates and C++ utilities are available at
\url{https://github.com/sjjaroch/leontovich-utils}
